Travel Track

Vacation Planning Application

Travel Track is an Android mobile app created to help users organize and manage their travel plans in one convenient location. Users can create an account and securely log in, create and manage multiple vacations, and add excursions associated with each vacation.

Each vacation includes important details such as the destination, hotel, travel dates, and special notes such as contact information. Users can also create, edit, and delete excursions while keeping them associated with the appropriate vacation.

Travel Track includes search and filter functionality to help users quickly locate their vacations, as well as reporting features that allow users to review their vacation information in an organized format. Input validation and password protection are incorporated to help protect user information and maintain data integrity.
